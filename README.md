## Installation and Setup
1. Clone the repository :`git clone https://github.com/urwashistudy/myapp.git`
2. Check branch to be feature-routes, else git checkout feature-routes
3. Install dependencies: `npm install`
4. Create .env file and update with latest env variables.
5. State the project : `npm run dev`

* Api endpoint: `http://localhost:4000/endpoint`
